# menu_nav.txt (T1640): the menu table of the closed loop menu navigator. Findings and evidence:
# docs/t1640-menu-state-findings.md. Everything here was read from guest memory of the recompiled title on the
# tsfp host (route replay of the Map Maker route, dumps at every button edge), NOT from xemu or hardware.
# conf= MEASURED  seen in guest memory dumps of the host run;
#       INFERRED  read from the disassembly, consistent with every dump but not exercised;
#       UNVERIFIED not observed at all.
#
# ---------------------------------------------------------------------------------------------------------------
# GRAMMAR (one record per line, blank lines and lines starting with # are comments, text after ' # ' is a comment)
#
#   widgets table=ADDR stride=N count=N [closing=S,S]   once, the table of UI page widgets (all menu lines refer to it)
#   menu ID key=value key=value ...                      one line per menu, values contain no spaces
#
# mem spec   [*]ADDR[+OFF][:W]     the T1633 form (docs/t1633-route-events-findings.md): W = 1, 2 or 4 bytes (default 4),
#                                  `*` = read the pointer at ADDR first, then OFF from it. Values are unsigned.
# page spec  @+OFF[:W]             EXTENSION E1: OFF/W inside the PAGE WIDGET that `page=` selected for the line.
# cond       SPEC OP VALUE[&MASK]  OP is == != < <= > >=, SPEC is a mem spec or a page spec, MASK is applied first.
#                                  Several conditions are comma separated and AND-ed.
#
# keys:
#   page=builder:0xVA   EXTENSION E2, which widget is the menu. Scan the `count` slots at `table + i*stride`. A slot is a
#                       candidate when its dword at +0 is non-zero (slot in use), its dword at +8 equals VA (the page
#                       builder function, a constant code address) and its state dword at +0x1b0 is not in `closing`
#                       (4 and 5 = page is closing or dead). Among candidates take the highest state, then the highest
#                       slot index. No candidate = the menu is not on screen. page=none = no page widget is required.
#                       (Heap pointers and the slot number of a page change from run to run, builder VAs do not.)
#   active=COND,...     the menu is on screen when the page was found AND every cond holds. Typically
#                       0x79094C==MODE (0x65 front end, 0x66 map editor, 0x64 preview / in game, 0x67 loading).
#   ready=COND,...      input is accepted now: all conds hold. The lines use state 3 (fully open, costs at most ~50 polls per
#                       page). A press at the edge poll of a page still in state 1 was MEASURED lost (1 sample), presses in state 2
#                       were accepted (4 of 4), so `>=2` may be used to go faster. Keep `@+0x170:4==0` (no live child page on top).
#   cursor=SPEC         the cursor index, 0 based, counts every selectable row incl. disabled ones. 0xFFFFFFFF = none yet.
#   count=SPEC          number of cursor rows (selectable rows incl. disabled ones).
#   axis=v|h            direction of cursor travel: v = DOWN increments, UP decrements.
#   wrap=0|1            1 = the cursor wraps from the last row to the first and back.
#   itemid=SPEC         dword with the id of the row under the cursor (a game constant per row, NOT the index).
#   items=walk(HEAD;next=+N;type=+N:T1|T2..;id=+N;text=+N;flags=+N;skip=MASK;grey=MASK)   EXTENSION E3, the row list.
#                       HEAD is a spec whose value is the first node. Follow `next` (dword at node+N) until 0. A node is a
#                       cursor row when the dword at node+(type offset) is one of T1|T2.. . Row k = the k th such node,
#                       and k is the cursor value. Per row: id = dword at node+N, text = POINTER at node+N to a NUL
#                       terminated ASCII string (8 bit text, localised at load time), flags = dword at node+N. A row with
#                       flags&skip is skipped by the cursor (title and hint rows) and a row with flags&grey is shown
#                       greyed and ignores the select press.
#   select=A back=B     the pad keys that activate the cursor row and go back one page.
#   dpad=0|1            (T1640, default 1) 0 = the menu does not take the d-pad (pointer / stick driven): the navigator never presses it, it waits up to 3 s for
#                       the cursor to be on the target and activates, else FAILS. The recorder then ends no range at d-pad presses (at = the select press).
#   selectby=id|name|index  (T1640, default id) what the RECORDER writes as `select=` for the activated row: the item id, the row text (percent encoded; only when it
#                       is non empty and unique among the rows the cursor does not skip, else the id, else the index) or the cursor index. name for lists whose
#                       ids are only list positions (profiles, saved maps).
#   conf=MEASURED|INFERRED|UNVERIFIED
#
# How a line is used (the closed loop): find the page, wait for `ready`, read cursor / count / itemid / items, choose UP or
# DOWN (shortest way if wrap=1, press once and re-read, because skipped rows move the cursor by more than one), press the
# direction 2+ polls and release 2+ polls, repeat until the row (by id or by text) is under the cursor, press A, then wait
# for this page to disappear or another builder to appear. If the page is unchanged and ready after N polls press A once more.
# What the grammar cannot say is listed at the end of docs/t1640-menu-state-findings.md (section Host requirements).
# ---------------------------------------------------------------------------------------------------------------

widgets table=0x6FEBE8 stride=0x23C count=20 closing=4,5   # conf=MEASURED, 20 slots to 0x701898, slot = struct of 0x23c bytes

# Pad keys are fed to the title as the ordinary d-pad / A / B bits. The UI turns them into widget +0xC4 (pressed or
# repeating, bit 16+k) and +0xC8 (held bit k, released bit 16+k) with k: 0 UP 1 DOWN 2 LEFT 3 RIGHT 4 A 5 B/BACK 6 X 7 Y
# 8 START 9 BLACK 10 WHITE 11 RT 12 LT (mask table at 0x6FEBB0). The left stick also moves the cursor (INFERRED).
