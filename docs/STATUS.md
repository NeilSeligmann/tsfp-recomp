# Status
Works (MEASURED during development, on Linux with llvmpipe and a real GPU): boot, intro movies, front-end menus, profile creation,
Story mode scenes, audio, keyboard/pad input. Known limits: some render paths are INFERRED from xemu source and may be wrong,
combat and long-session stability are not fully verified, many XDK functions are unimplemented and end in a named stop report,
online/multiplayer features are not supported. Windows/macOS are untested.
The full decompilation research log, proofs and task history live on the original development branch, not here.
